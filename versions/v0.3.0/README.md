# lemon's NewTab Pro v0.3.0

基于 Chrome Manifest V3 的**免 Node.js、插件化**新标签页。默认画面只有南瓜背景和右上角的插件管理按钮；时钟、搜索、导航以及其他功能都由可选插件提供。

> **当前阶段：预览版。** 已通过源码和模拟测试，但运行环境无法完成真实 Chrome 扩展交互验收。首次使用请先备份旧版本并安装少量插件测试。

## 零命令行安装（用户）

1. 解压 `lemon-NewTab-Pro-v0.3.0.zip`。
2. Chrome 打开 `chrome://extensions`，开启开发者模式，点击“加载已解压的扩展程序”，选择包含 `manifest.json` 的目录。
3. 打开新标签页，点击右上角插件管理图标。
4. 两种办法安装插件：
   - 点击 **导入插件文件夹**，选择含 `plugin.json`、`main.js` 的插件文件夹；
   - 从**官方示例**下拉框选择示例，点击“安装示例”。
5. 安装后在列表里**手动启用**。插件有设置时，点击“设置”。无需 Node.js、npm、打包步骤，也不必编辑注册清单。

**注意**：浏览器选择的文件夹会被读取并保存成扩展自己的本地副本（IndexedDB）；它不是监控磁盘目录，源文件更改后需要再次导入并确认更新。插件卸载不会删除原始文件夹，也不会自动删除其设置与数据。

## 目录

```
manifest.json            # MV3 元数据 / CSP
index.html / index.css   # 仅背景、容器和管理器
index.js                 # 安全宿主、消息仲裁、设置、加载器
plugin-schema.js         # 插件清单与设置校验，兼容旧协议
plugin-packages.js       # 文件夹导入、资源验证、IndexedDB 快照
sandbox.html / sandbox.js / sandbox.css  # 每插件独立沙箱
plugins/                 # 兼容旧版“打包内插件”及空注册清单
examples/                # 19 个离线可选示例及 catalog.json
templates/starter/        # 最简二文件模板
scripts/                 # 可选的开发/CI 脚本（运行扩展无需执行）
tests/                   # 项目测试（仅维护者使用）
PLUGIN-SPEC.md           # 插件格式、隔离和权限规范（优先阅读）
PLUGIN-DEVELOPMENT.md    # 10 分钟上手教程
```

## 兼容性及更新

- **旧版 v0.2.0 插件**仍然可以使用 `window.LemonPlugin = {mount(root, api) {...}}`、8 类设置控件、存储、图片资源、外链和背景 API。
- v0.3.0 新增 `Lemon.mount(...)` 快速入口，以及更小的必填 `plugin.json`。
- 已有 `plugins/registry.json` 的**打包内插件**仍可加载，但新用户无需运行 `build-registry.mjs`。
- **v0.2 → v0.3 迁移建议**：备份扩展目录，使用升级补丁覆盖核心文件；`plugins/` 不应被覆盖。原有 Chrome 存储和已打包插件状态会保留。新安装的本地插件存入 IndexedDB。
- 请避免改变已加载未打包扩展的目录路径，Chrome 可能将其视作另一扩展 ID，原有浏览器存储无法自动迁移。

## 已知限制与安全说明

- Chrome 不允许扩展无授权地扫描电脑上的任意文件夹，**必须由用户选取目录**；本版本不支持自动监测外部文件修改。
- 沙箱隔离代码执行、DOM 样式、绝大多数浏览器能力，但**不保证完全消除恶意脚本风险或资源滥用**；不应安装不可信代码。
- 只能读声明资源和许可数据；沙箱 `connect-src 'none'`，不能直接联网获取脚本；外链需用户确认。这里并未绕过 Chrome 的安全限制。
- Chrome Web Store 的发行审查由商店决定。用户选择并存储的脚本只在不具扩展权限的沙箱内运行，但商店仍可能要求明确的功能披露和隐私说明。
- 宿主目前不提供插件在线更新、同步、签名/信任链、网络代理、插件间共享数据库或任意文件写入功能。
- 本地插件数据库、设置与数据都绑定当前扩展安装；删除扩展或清理扩展数据可能丢失。

## 版本历史

v0.3.0：免 Node.js 文件夹导入、示例一键安装、最简两文件插件、隔离/冲突约束、字体资源、插件卸载、设置与数据继续独立。详见 `RELEASE-NOTES.md`。
