lemon's NewTab Pro v0.3.1 修复补丁（从 v0.3.0 升级）

故障：导入插件后提示安装成功，但插件列表仍为空。
修复：兼容 v0.3.0 IndexedDB 旧插件记录，并修正安装后的核验与显示数量。

1. 请先备份 v0.3.0 目录；请勿卸载现有 Chrome 扩展。
2. 将本补丁 ZIP 里的文件覆盖到原扩展根目录（有 manifest.json 的位置）。
3. 请勿删除 plugins/、个人插件目录或浏览器的扩展数据。
4. 打开 chrome://extensions，重新加载 lemon's NewTab Pro，重新打开新标签页。
5. 插件管理列表应重新显示之前安装到 IndexedDB 的插件；如未立即出现，点击“刷新插件列表”。
6. 插件更新或导入后的默认状态仍是禁用，请手动启用所需插件。

注意：务必在原来的扩展目录上覆盖升级，避免因扩展 ID 变化而无法读取旧 IndexedDB 数据。
此补丁不需要 Node.js，不含 plugins/ 文件，不会主动清空本地插件数据库。
