# lemon's NewTab Pro v0.1.1 — 启动修复与极简主页

本版本将此前 v0.1.0 的启动修复正式发布为 **v0.1.1**。插件格式与现有数据保持兼容。

- 修复插件可能持续显示“正在启动插件”的问题：宿主读取已注册的本地脚本后交由沙箱执行，并使用显式消息握手。
- 启动超过 12 秒显示错误和重试按钮，不再无限等待。
- 主页删除品牌横幅、介绍、页脚及空插件提示；无插件时只显示默认背景和插件管理按钮。
- 不再由核心绘制插件标题栏，插件自行决定展示内容。
- `plugins/` 默认不安装功能插件；15 个可选测试插件仅放在 `examples/`。
- 升级用的核心补丁不包含 `plugins/`，不会主动覆盖已安装插件和本地清单。

测试环境无法安装 Chrome 扩展，因此虽有自动化测试，尚需在实际 Chrome 中验证扩展运行。
